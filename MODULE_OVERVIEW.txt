1. Install dependencies:
   $ cd samlauth && composer install --no-dev

2. Deploy to FreePBX:
   $ sudo cp -r samlauth /var/www/html/admin/modules/
   $ sudo chown -R asterisk:asterisk /var/www/html/admin/modules/samlauth

3. Install module:
   Admin → Module Admin → Install "SAML Authentication"

4. Configure:
   Admin → SAML Authentication → Add Identity Provider

5. Test:
   https://your-freepbx.com/admin/modules/samlauth/endpoints/login.php

📖 See DEPLOYMENT_GUIDE.md for detailed instructions
